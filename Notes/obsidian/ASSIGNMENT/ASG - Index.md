## 📈 Progression & Coursework Milestones

1. **Functions and Modular Arithmetic (01):** Decomposing arithmetic operations into pure functions with explicit parameter passing and return values.
2. **2D Coordinate Printing (02–03):** Mastering nested iteration, spacing offsets, and conditional boundary masks across 5 pyramid variants, hollow boxes, and symmetric butterflies.
3. **Data Aggregation & Sorting (04–05):** Implementing university credit-hour weighting rules to construct sorted merit ranks, followed by string comparison via ASCII values and `strcmp`.
4. **Stateful Console Architectures (06–07):** Designing menu-driven systems managing parallel entity collections (students and library book inventories) with multi-criteria search and update capabilities.
5. **Recursion Deep Dive (08):** Eliminating iterative constructs in favor of self-similar call frames for numerical sequences, primality detection, and raw pointer string reversal.
6. **File I/O & Linked Data Structures (09–10):**
   - **Assignment 09:** Ingests seven distinct course text files (`1101_CSE.txt` through `1107_MATH.txt`), joins records with `name_cg.txt`, and generates persistent transcripts.
   - **Assignment 10:** Re-architects the marksheet system using self-referential node pointers (`struct Student *next`), demonstrating the evolutionary transition from fixed arrays to dynamic linked lists.
