# Tag Glossary & Live Category Directory

> [!abstract] Tag Directory
> This glossary catalogs all controlled tags across the CSE 1101 knowledge base. Each topic tag includes an embedded Obsidian live query block that dynamically gathers every matching note in the vault.

---

## 1. Type Tags
Each note belongs to exactly one structural type:
- `type/lecture`: Notes originating from classroom lecture programs (`CLASS/`).
- `type/lab`: Experiments from structured laboratory sessions (`LAB/`).
- `type/assignment`: Graded coursework assignments (`ASSIGNMENT/`).
- `type/project`: Major term projects, midterm exams, and final exams (`LAB_PROJECT/`).
- `type/practice`: Drill problems, LeetCode solutions, C Book exercises, and tutorials (`PRACTICE/`).
- `type/reference`: Vault navigation, taxonomy guides, and reference documents.
- `type/archive`: Post-mortems, legacy logs, bug analyses, and historical prototypes (`99_archive/`).
- `type/index`: Navigation hub index notes for folders and major sequences.

---

## 2. Difficulty Level Tags
- `level/basic`: Introductory syntax, elementary operators, linear execution, basic loops.
- `level/intermediate`: Pointers, string manipulations, recursion, file operations, structures.
- `level/advanced`: Dynamic linked lists, custom binary protocols, multi-file modular GUI systems, convolution filters.
