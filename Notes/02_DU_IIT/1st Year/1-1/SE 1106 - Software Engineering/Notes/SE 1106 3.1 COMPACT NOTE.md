# 3.1 The Management Spectrum — Compact Note

---

## Core Concept: The Four P's (ordered by priority)

| P | Focus |
|---|-------|
| **People** | Most important — SE is a human endeavor |
| **Product** | Define objectives, scope, constraints before planning |
| **Process** | Framework + task sets + umbrella activities |
| **Project** | Plan, monitor, control to manage complexity |

---

## 3.1.1 People

- **PM-CMM** (by SEI) — companion to Software CMM
- 8 key practice areas: **Recruiting · Selection · Performance Mgmt · Training · Compensation · Career Dev · Org & Work Design · Team/Culture Dev**
- High people-management maturity → better SE practices

---

## 3.1.2 Product

- Before planning, establish: **Objectives + Scope + Alternatives + Constraints**

| Term | Meaning |
|------|---------|
| **Objectives** | Customer's goals (the *what*, not *how*) |
| **Scope** | Data, functions, behaviors — bounded quantitatively |

- Without these → can't estimate cost, risk, tasks, or schedule

---

## 3.1.3 Process

| Layer | What it is |
|-------|------------|
| **Framework activities** | Core activities for all projects |
| **Task sets** | Tasks, milestones, work products, QA points — adapt framework to project |
| **Umbrella activities** | SQA, SCM, Measurement — span the entire process |

---

## 3.1.4 Project

- Planned & controlled projects = **only way to manage complexity**
- **1998 stats:** 26% failed outright, 46% had cost/schedule overruns
- Avoid failure → watch **warning signs** · know **critical success factors** · use **commonsense planning**
