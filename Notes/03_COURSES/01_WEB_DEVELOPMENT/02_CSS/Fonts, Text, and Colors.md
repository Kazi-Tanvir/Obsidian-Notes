# Fonts, Text, and Colors

## What's the Actual Use?
These properties control the visual aesthetics of your text and the color palette of your website.

## Other Common Use Cases
- Changing line height for better readability.
- Using Google Fonts or local font files.

## Documentation & Code
Common properties include `font-family`, `font-size`, `text-align`, `color`, and `background-color`.

````css
.content {
    color: #333; /* Hex color */
    background-color: rgb(255, 255, 255);
    font-family: 'Arial', sans-serif;
    font-size: 1.2rem;
    line-height: 1.6;
    text-align: center;
    text-transform: capitalize;
}
````
