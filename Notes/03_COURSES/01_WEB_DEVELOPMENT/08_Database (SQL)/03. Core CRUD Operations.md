> [!info] Quick Summary
> 
> CRUD stands for **C**reate, **R**ead, **U**pdate, and **D**elete. These are the four primary operations you will perform when interacting with records inside a database table.

## 1. Create (Inserting Data)

Used to add new rows of data into a table.

### Insert a Single Row

Specify the columns you want to fill, followed by their respective values in the exact same order.

```sql
INSERT INTO users (name, email, gender, date_of_birth, salary)
VALUES ('Harry', 'harry@example.com', 'Male', '1995-08-15', 75000);
```

### Insert Multiple Rows (Best Practice)

> [!tip] Efficiency
> 
> Inserting multiple rows in a single query is much faster and more efficient than running multiple individual `INSERT` statements.

```sql
INSERT INTO users (name, email, gender)
VALUES ('Aarav', 'aarav@example.com', 'Male'),('Sneha', 'sneha@example.com', 'Female'),('Ishan', 'ishan@example.com', 'Male');
```

_Note: Columns with `AUTO_INCREMENT` (like IDs) or `DEFAULT` values (like timestamps) will populate automatically if omitted._

## 2. Read (Retrieving Data)

Used to fetch and view data from your tables.

### Select All Columns

The asterisk (`*`) is a wildcard that grabs every column available in the table.

```sql
SELECT * FROM users;
```

### Select Specific Columns

For better performance, specifically request only the columns you need.

```sql
SELECT name, email, gender FROM users;
```

## 3. Update (Modifying Data)

Used to change existing records in a table.

> [!warning] Critical Warning
> 
> Always use a `WHERE` clause when updating! If you run an `UPDATE` without a `WHERE` clause, it will overwrite that column for **every single row** in your entire table.

```sql
-- Update a single user's salary based on their unique ID
UPDATE users 
SET salary = 80000 
WHERE id = 5;

-- Update multiple columns at once
UPDATE users 
SET salary = 85000, email = 'newemail@example.com' 
WHERE name = 'Aarav';
```

## 4. Delete (Removing Data)

Used to permanently remove rows from a table.

### Deleting Specific Rows

Like `UPDATE`, the `DELETE` command relies heavily on the `WHERE` clause to target the correct data.

```sql
DELETE FROM users 
WHERE id = 3;
```

> [!example] Pro-Tip: The "Select-First" Strategy
> 
> Before running a destructive `DELETE` operation, run a `SELECT` query using the exact same `WHERE` clause. This allows you to preview exactly which records will be affected before they are permanently erased.
> 
> ```
> -- Step 1: Preview the data
> SELECT * FROM users WHERE salary < 50000;
> 
> -- Step 2: Execute the deletion with confidence
> DELETE FROM users WHERE salary < 50000;
> ```
