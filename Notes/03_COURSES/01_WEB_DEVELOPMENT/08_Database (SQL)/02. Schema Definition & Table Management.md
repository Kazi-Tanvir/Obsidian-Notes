> [!info] Quick Summary
> 
> This page covers Data Definition Language (DDL). It includes how to create databases, structure your tables, choose the right data types, and modify existing schemas without losing data.

## Creating Databases & Tables

Before storing data, you must create a container (Database) and define the strict structure (Table) that the data will follow.

### Database Creation

Creates a new database and sets it as the active context for subsequent queries.

```sql
CREATE DATABASE starter_sql;
USE starter_sql; -- Mandatory: Tells MySQL which DB to run queries against
```

### Table Creation & Data Types

Defines a new table. Every column must have a specific data type and can optionally have constraints.

```sql
CREATE TABLE users (
id INT AUTO_INCREMENT PRIMARY KEY,
    name VARCHAR(100) NOT NULL,
    email VARCHAR(150) UNIQUE NOT NULL,
    gender ENUM('Male', 'Female', 'Other'),
    date_of_birth DATE,
    is_active BOOLEAN DEFAULT TRUE,
    created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
);
```

### Common Data Types Reference

- `INT`: Whole numbers (used heavily for IDs).
- `VARCHAR(n)`: Variable-length strings up to `n` characters. Perfect for names, emails, etc.
- `ENUM('a', 'b')`: Restricts the column to accept _only_ the predefined list of string values.
- `DATE`: Stores dates in `YYYY-MM-DD` format.
- `TIMESTAMP`: Stores exact date and time. Often paired with `DEFAULT CURRENT_TIMESTAMP` to auto-log creation times.
- `BOOLEAN`: Stores `TRUE` (1) or `FALSE` (0).


## Modifying Existing Schemas

Requirements change, and you will often need to update your table structures after they've been created.

### 1. Altering Columns (`ALTER TABLE`)

Used to add, drop, or change the data type of columns in an existing table.

```sql
-- Add a new column
ALTER TABLE users ADD COLUMN phone VARCHAR(15);

-- Remove an existing column
ALTER TABLE users DROP COLUMN phone;

-- Modify an existing column's data type or constraints
ALTER TABLE users MODIFY COLUMN name VARCHAR(255) NOT NULL;
```

### 2. Renaming Tables (`RENAME`)

Changes the name of an existing table.

```sql
RENAME TABLE users TO customers;
```

### 3. Deleting Schemas (`DROP`)

> [!warning] Danger Zone
> 
> `DROP` permanently deletes the table/database and **all the data** inside it. It cannot be easily undone.

```sql
-- Delete a table completely
DROP TABLE IF EXISTS customers;

-- Delete an entire database completely
DROP DATABASE starter_sql;
```
