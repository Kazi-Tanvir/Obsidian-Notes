# SEO and Core Web Vitals

## What's the Actual Use?
SEO (Search Engine Optimization) ensures your site is discoverable by search engines. Core Web Vitals are a set of metrics that measure the speed, responsiveness, and visual stability of a page.

## Real-Life Analogy
Think of SEO as the signage and street address for a physical shop. If the sign is clear and the address is easy to find, more customers (users) will walk in. Core Web Vitals are like the cleanliness and speed of service inside the shop.

## Other Common Use Cases
- Using `<meta>` tags to control how a site looks when shared on social media (Open Graph).
- Optimizing Largest Contentful Paint (LCP) to keep users from leaving a slow-loading page.

## Documentation & Code
Key elements include the `<title>`, `<meta name="description">`, and semantic tags.

````html
<head>
    <!-- SEO Basics -->
    <title>Mastering HTML for SEO</title>
    <meta name="description" content="Learn how to optimize your HTML for search engines and performance.">
    
    <!-- Open Graph for Social Media -->
    <meta property="og:title" content="HTML SEO Guide">
    <meta property="og:image" content="thumbnail.jpg">
</head>
````
