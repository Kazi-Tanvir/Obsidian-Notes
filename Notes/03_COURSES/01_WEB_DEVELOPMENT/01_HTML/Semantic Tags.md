# Semantic Tags

## What's the Actual Use?
Semantic tags describe their meaning to both the browser and the developer. Instead of using generic `<div>` tags everywhere, semantic tags tell search engines and screen readers exactly what each part of the page is for.

## Other Common Use Cases
- Improving accessibility for users with screen readers.
- Helping search engines index the content of your page more accurately.

## Documentation & Code
Common semantic tags include `<header>`, `<footer>`, `<main>`, `<article>`, `<section>`, `<nav>`, and `<aside>`.

````html
<header>
    <h1>Site Title</h1>
    <nav>Navigation Links</nav>
</header>

<main>
    <article>
        <h2>Article Title</h2>
        <p>This is the main content.</p>
    </article>
</main>

<footer>
    <p>&copy; 2026 My Website</p>
</footer>
````
