# 1. Database Fundamentals & Setup

> [!info] Quick Summary
> This page covers the foundational concepts of databases, the difference between relational and non-relational architectures, and the basic commands needed to install and secure MySQL.

## Core Concepts

* `Database (DB):` A structured way to store data so it is easily accessible, manageable, and updatable. Handles massive scale much better than flat files.
* `Analogy:` Think of a Database as an Excel Workbook, Tables as individual Sheets, and Rows as the data entries.
* `Query:` A specific request or command sent to the database to retrieve, create, update, or delete data.
* `DBMS (Database Management System):` The software layer that interacts with the end-user, applications, and the database itself (e.g., MySQL, PostgreSQL).

---

## Architecture: Relational vs. Non-Relational

> [!abstract] Architectural Differences
> Choosing the right architecture depends on whether your data needs a strict, predictable structure or flexible, dynamic formatting.

| Feature | Relational (SQL / RDBMS) | Non-Relational (NoSQL) |
| :--- | :--- | :--- |
| **Structure** | Tables with Rows and Columns. | Documents, Key-Value pairs, or Graphs. |
| **Schema** | Strict, pre-defined schema. | Flexible, dynamic schema. |
| **Use Case** | Structured data, complex relations, financial ledgers. | Unstructured data, heavy read operations, rapidly changing data. |
| **Examples** | MySQL, PostgreSQL, MS SQL. | MongoDB, Cassandra, Redis. |

## Setup & Installation (Linux/Ubuntu)

Below are the essential commands to install, secure, and configure MySQL on a Linux (Ubuntu) environment. 

### 1. Install MySQL Server
Updates the package list and installs the MySQL server package.
```bash
sudo apt update
sudo apt install mysql-server 
```
### 2. Secure the Installation

Runs a security script to set up password validation policies, remove anonymous users, and disable remote root logins.

Bash

```bash
sudo mysql_secure_installation
```

### 3. Access the MySQL Prompt

Logs you into the MySQL monitor as the root user so you can start executing SQL queries.

Bash

```bash
sudo mysql
```

### 4. Create a New User & Grant Privileges

_Run these commands inside the MySQL prompt._ Creating a dedicated user is safer than using the root user for day-to-day backend development.

SQL

```sql
-- Create a new user with a specific password
CREATE USER 'username'@'localhost' IDENTIFIED BY 'password';

-- Grant all privileges to the new user across all databases (*.*)
GRANT ALL PRIVILEGES ON *.* TO 'username'@'localhost' WITH GRANT OPTION;

-- Reload the grant tables to apply the new privileges immediately
FLUSH PRIVILEGES;
```

> [!tip] Workbench Connection After setting up the server and user, open **MySQL Workbench**, click the `+` icon next to MySQL Connections, and enter the username and password you just created to connect your graphical interface to the backend.
