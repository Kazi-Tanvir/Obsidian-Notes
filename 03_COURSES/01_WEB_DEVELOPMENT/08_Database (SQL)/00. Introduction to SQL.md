# Introduction to SQL

Structured Query Language (SQL) is the standard language used to communicate with Relational Database Management Systems (RDBMS) like MySQL. It provides a structured, highly efficient way to store, retrieve, and manipulate data, solving the computational and structural limitations of flat files or spreadsheets. 

---

## What SQL Can Do

* ``Execute CRUD Operations:`` Seamlessly **C**reate, **R**ead, **U**pdate, and **D**elete records within a database to manage application state dynamically.
* `Handle Big Data:` Efficiently manage and query millions of data points without the performance bottlenecks found in Excel.
* `Establish Relationships:` Link different data tables together (e.g., linking a user's account to their specific addresses) using standard schemas, Primary Keys, and Foreign Keys.
* `Filter and Sort:` Retrieve specific subsets of data based on complex conditions using clauses and logical operators.
* `Aggregate Data:` Perform mathematical calculations on data sets (like finding averages, sums, or counting users) directly within the database engine using built-in functions.
* `Automate Workflows:` Execute automatic database actions through Triggers and save complex, repetitive queries using Views and Stored Procedures.
