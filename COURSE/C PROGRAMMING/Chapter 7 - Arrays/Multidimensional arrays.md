# Multidimensional arrays
An array can be of 2 dimension/ 3 dimension/ n dimensions.
A 2 dimensions array can be defined like this:

```c
int arr[3][2] = {{1, 4}, 
                 {7, 9},
                 {11, 22}};
```
We can access the elements of this array as `arr[0][0]`, `arr[0][1]` & so on ...
