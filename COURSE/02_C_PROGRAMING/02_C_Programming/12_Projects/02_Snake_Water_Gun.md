# Project 2: Snake, Water, Gun

## Goal
Create a C program capable of playing the "Snake, Water, Gun" game with you.

## Rules
- Choice 1: Snake
- Choice 2: Water
- Choice 3: Gun

### Logic
- Snake beats Water.
- Water beats Gun.
- Gun beats Snake.

## Requirements
- The program should take the user's choice.
- The computer should generate a random choice.
- Compare choices and print the result (Win, Lose, or Draw).

## Implementation Tips
- Use character inputs ('s', 'w', 'g').
- Use a random number generator to pick the computer's choice.
- Use a series of `if-else` statements to decide the winner.
