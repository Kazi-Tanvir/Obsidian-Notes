# Introduction to CSS

## What's the Actual Use?
Cascading Style Sheets (CSS) is used to style and lay out web pages—for example, to alter the font, color, size, and spacing of your content, split it into multiple columns, or add animations and other decorative features.

## Other Common Use Cases
- Making a website responsive across different devices (Mobile, Tablet, Desktop).
- Improving user experience with consistent visual feedback.

## Documentation & Code
CSS works by selecting HTML elements and applying properties to them.

````css
/* Selector { Property: Value; } */
p {
    color: blue;
    font-size: 16px;
}
````
