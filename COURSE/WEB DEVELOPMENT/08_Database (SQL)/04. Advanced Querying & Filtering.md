> [!info] Quick Summary
> 
> Once you have data in your tables, you rarely want to select _all_ of it at once. This page covers how to refine your `SELECT` statements using conditions, logical operators, pattern matching, and pagination.

## 1. Conditional Filtering

The `WHERE` clause acts as a filter to return only the rows that meet specific criteria.

### Basic Operators (`=`, `<`, `>`, `<=`, `>=`)

```sql
-- Find users who make more than 60k
SELECT * FROM users WHERE salary > 60000;

-- Find users based on exact match
SELECT * FROM users WHERE gender = 'Female';
```

### Checking for Nulls (`IS NULL`, `IS NOT NULL`)

You cannot use `=` to check for NULL values.

```sql
SELECT * FROM users WHERE date_of_birth IS NULL;
```

### The `BETWEEN` Operator

Selects values within a given range (inclusive). Great for dates and numbers.

```sql
SELECT * FROM users 
WHERE date_of_birth BETWEEN '1990-01-01' AND '1999-12-31';
```

### The `IN` Operator

Allows you to specify multiple exact values in a `WHERE` clause. It is a shorthand for multiple `OR` conditions.

```sql
SELECT * FROM users 
WHERE gender IN ('Male', 'Female'); 
-- Much cleaner than: WHERE gender = 'Male' OR gender = 'Female'
```

## 2. Logical Operators (`AND`, `OR`, `NOT`)

Used to combine multiple conditions together.

- `AND`: Returns a record if _all_ conditions separated by AND are TRUE.
- `OR`: Returns a record if _any_ of the conditions separated by OR is TRUE.
- `NOT`: Reverses the boolean output of the condition.

```sql
-- Using AND
SELECT * FROM users 
WHERE gender = 'Female' AND salary > 70000;

-- Using OR
SELECT * FROM users 
WHERE gender = 'Male' OR salary > 65000;

-- Using NOT (and combining operators)
SELECT * FROM users 
WHERE NOT gender = 'Male' AND salary > 50000;
```

## 3. Pattern Matching (`LIKE` & Wildcards)

Used in a `WHERE` clause to search for a specified pattern in a column.

- `%` (Percent Sign): Represents zero, one, or multiple characters.
- `_` (Underscore): Represents a single, specific character.

```sql
-- Finds any name starting with 'A' (e.g., Aarav, Ayush)
SELECT * FROM users WHERE name LIKE 'A%';

-- Finds any email ending with '@example.com'
SELECT * FROM users WHERE email LIKE '%@example.com';

-- Finds any name where the SECOND letter is 'a' (e.g., Harry, Raj)
SELECT * FROM users WHERE name LIKE '_a%';
```

## 4. Sorting & Pagination

When sending data to a frontend application, you often need to sort the data and break it into "pages" to prevent loading massive payloads all at once.

### Sorting (`ORDER BY`)

Sorts the result set in Ascending (`ASC` - default) or Descending (`DESC`) order.

```sql
-- Youngest users first (descending date of birth)
SELECT * FROM users ORDER BY date_of_birth DESC;
```

### Pagination (`LIMIT` & `OFFSET`)

- **`LIMIT`**: Restricts the maximum number of rows returned.
- **`OFFSET`**: Skips a specific number of rows before beginning to return the rows.

```sql
-- Get the top 5 highest paid users
SELECT * FROM users 
ORDER BY salary DESC 
LIMIT 5;

-- Skip the first 10 rows, then return the next 5 (e.g., Page 3 of a UI)
SELECT * FROM users 
LIMIT 5 OFFSET 10;

-- Shorthand syntax: LIMIT offset, row_count
SELECT * FROM users LIMIT 10, 5;
```
