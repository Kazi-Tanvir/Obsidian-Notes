> [!info] Quick Summary
> 
> SQL isn't just for retrieving raw data; it can also perform calculations, format text, and summarize information directly within the database using built-in functions and grouping clauses.

## 1. Aggregate Functions

Aggregate functions perform a calculation on a set of values and return a single summarizing value.

- `COUNT()`: Returns the number of rows.
- `SUM()`: Returns the total sum of a numeric column.
- `AVG()`: Returns the average value of a numeric column.
- `MIN()` / `MAX()`: Returns the smallest or largest value in a column.    

```sql
-- Find the total number of users
SELECT COUNT(*) FROM users;

-- Get the highest and lowest salary in the company
SELECT MIN(salary) AS min_salary, MAX(salary) AS max_salary FROM users;

-- Calculate the total amount paid to all female employees
SELECT SUM(salary) AS total_paid FROM users WHERE gender = 'Female';
```

_(Note: The `AS` keyword creates an "alias", renaming the output column for better readability)._

## 2. Grouping Data (`GROUP BY` & `HAVING`)

Sometimes you want to calculate aggregates for specific _categories_ rather than the whole table (e.g., finding the average salary _per gender_).

### `GROUP BY`

Groups rows that have the same values into summary rows.

```sql
-- Get the average salary for each gender
SELECT gender, AVG(salary) AS avg_salary 
FROM users 
GROUP BY gender;
```

### `HAVING` (Filtering Groups)

> [!warning] WHERE vs. HAVING
> 
> You **cannot** use a `WHERE` clause to filter aggregated data (like `AVG` or `COUNT`). `WHERE` filters rows _before_ grouping, while `HAVING` filters _after_ grouping.

```sql
-- Find genders where the average salary is strictly greater than 60,000
SELECT gender, AVG(salary) AS avg_salary 
FROM users 
GROUP BY gender 
HAVING avg_salary > 60000;
```

### `WITH ROLLUP`

Added to `GROUP BY` to generate extra rows that represent subtotals and a grand total.

```sql
-- Returns average salary per gender, plus a final row with the overall average
SELECT gender, AVG(salary) 
FROM users 
GROUP BY gender WITH ROLLUP;
```

## 3. Helpful Built-in Functions

MySQL includes many functions to transform your data on the fly.

### String Functions

```sql
-- Lowercase the name and get its character length
SELECT LOWER(name), LENGTH(name) FROM users;

-- Combine strings together (e.g., generating a username)
SELECT CONCAT(LOWER(name), '123') AS generated_username FROM users;
```

### Date & Time Functions

```sql
-- Get the current date and time
SELECT NOW();

-- Extract just the year from a date column
SELECT YEAR(date_of_birth) FROM users;

-- Find the difference in days between today and their birthdate
SELECT name, DATEDIFF(CURRENT_DATE(), date_of_birth) AS days_alive FROM users;
```

### Math & Conditional Functions

```sql
-- Round decimals, get the floor, or get the ceiling
SELECT ROUND(salary), FLOOR(salary), CEIL(salary) FROM users;

-- Conditional IF: IF(condition, value_if_true, value_if_false)
SELECT name, IF(salary > 70000, 'High Earner', 'Standard') AS earning_status FROM users;
```
