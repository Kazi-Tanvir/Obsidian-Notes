# Ubuntu & CLI Basics

## 1. File System & Paths
* **Root**: `/` (The starting point of the entire file system)
* **Home**: `~` (Translates to the current user's directory, e.g., `/home/kazitanvir/`)
* **Absolute Path**: The exact, full path from the root `/`.
* **Relative Path**: The path relative to the current working directory.

## 2. Terminal Symbols & Expressions
* `( )` -> Parentheses
* `{ }` -> Curly braces
* `[ ]` -> Square braces/brackets
* `!` -> Bang (Commonly used for history or logical NOT)
* `*` -> Asterisk (Wildcard - matches anything)
* `?` -> Question Mark (Wildcard - matches a single character)
* `-` -> Dash (Used for flags/options)
* `--` -> Double Dash (Used for long-form flags)
* `&` -> Ampersand (Run command in background)
* `&&` -> Double Ampersand (Logical AND - only run if previous command succeeds)
* `|` -> Pipe (Pass output of one command to another)
* `||` -> Double Pipe (Logical OR - only run if previous command fails)
* `~` -> Tilde (Home directory)
* `.` -> Dot (Current directory)
* `..` -> Double Dot (Parent directory)
* `#` -> Hash/Pound (Comment or root user prompt)
* `$` -> Dollar (Variable prefix or standard user prompt)
* `/` -> Forward Slash (Root directory or path separator)
* `\` -> Backslash (Escape character)
* `"` -> Double Quote (Soft quoting - allows variable expansion)
* `'` -> Single Quote (Hard quoting - literal string)
* `>` -> Greater Than (Output redirection - overwrite)
* `>>` -> Double Greater Than (Output redirection - append)
* `<` -> Less Than (Input redirection)

## 3. Directory & Navigation Commands
* `pwd` : Print Working Directory (shows current location).
* `ls` : List folders and files.
* `cd <folder>` : Change directory (go into a folder).
* `cd ..` : Go up one directory level.
* `cd ../..` : Go up two directory levels.
* `mkdir <folder>` : Create a new folder.
  * `mkdir -p a/b/c/d` : Create multiple nested folders at once.
* `Ctrl + L` : Scrolls the page to the newest line (effectively clears the terminal view).

## 4. File Management Commands
* `touch <file>` : Create empty files (e.g., `touch test.txt` or `touch dir1/test.txt`).
* `rm <file>` : Delete a file.
* `rmdir <dir>` : Delete an empty directory.
* `cp <source> <destination>` : Copy a file.
  * `cp -r <source> <destination>` : Copy folders recursively.
* `mv <source> <destination>` : Move or rename a file/folder.
* `vi <file>` : Open the vi text editor to edit a file.
* `cat <file>` : Read and print the entire contents of a file to the terminal.
* `diff <file1> <file2>` : Compare the differences between two files.
* `man <command>` : Opens the manual/description for a specific command.

## 5. Vi Text Editor
Vi is a modal editor. You must switch between modes to perform different actions.

* **Modes**:
  * `Command Mode`: Default mode for navigation and commands. (Press `Esc` to return here)
  * `Insert Mode`: Mode for typing text. (Press `i` to enter)
  * `Visual Mode`: Mode for selecting text. (Press `v` to enter)

* **Navigation (Command Mode)**:
  * `h`, `j`, `k`, `l` : Move left, down, up, right (arrow key alternatives).
  * `w` : Move forward one word.
  * `b` : Move back one word.
  * `0` (zero) : Move to start of line.
  * `$` : Move to end of line.
  * `gg` : Go to start of file.
  * `G` : Go to end of file.

* **Editing (Command Mode)**:
  * `x` : Delete a single character.
  * `dd` : Delete (cut) the current line.
  * `yy` : Yank (copy) the current line.
  * `p` : Paste after the cursor.
  * `u` : Undo last action.

* **Exiting & Saving (from Command Mode)**:
  * `:w` : Write (save) the file.
  * `:q` : Quit.
  * `:wq` or `:x` : Save and quit.
  * `:q!` : Quit without saving changes.

## 6. Output Redirection & Chaining

**Redirection**
* `>` : Writes output to a file (overwrites). 
  * *Example:* `echo "text" > text.txt`
  * *Example:* `ls > ls-out.txt` (saves the `ls` output to a text file)
* `>>` : Appends output to the end of a file.
  * *Example:* `echo "text" >> text.txt`

**Chaining & Filtering**
* `grep "<text>"` : Finds/filters for specific text.
* `wc` : Word count.
* `&&` : Multiple command execution (Logical AND). 
  * *Analogy:* Think of it like a strict dependency checklist—the second command will *only* execute if the first command succeeds without errors.
* `|` : Piping. 
  * *Analogy:* Imagine a factory assembly line. The output produced by the first machine (command) is handed directly onto the conveyor belt to become the input raw material for the next machine.
  * *Example:* `ls /bin | grep "tar" | wc` (Lists all files in `/bin`, filters only those containing "tar", and counts them).
