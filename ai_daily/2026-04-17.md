## Logged Activities & Context
### Dynamic SQL Portfolio Transition
- **Context**: Replacing static project arrays with active database fetching.
- **Actions Taken**: Configured SQL schemas for project lists and reviews. Whitelisted image CDN hosting domains (ImgBB/Postimages) instead of using Imgur.
- **Key Takeaways**: Imgur terms of service restrict hotlinking for web CDNs. Direct image host links provide stable image loading.

### Netlify Deployment Crash Debugging
- **Context**: Fixing compilation failures on Netlify.
- **Actions Taken**: Resolved CommonJS/ESM module conflicts by removing `"type": "module"` from `package.json` to prevent serverless handler errors.
- **Key Takeaways**: Netlify's auto-generated serverless wrappers rely on CommonJS, which conflicts with global ES Module configurations.

### Git Sync Issues
- **Context**: Fixing push rejections due to out-of-sync remote commits.
- **Actions Taken**: Ran `git pull origin main --rebase` to merge remote updates on top of local work.
- **Key Takeaways**: Direct changes on GitHub (like editing environment files) require local updates before subsequent pushes are allowed.
