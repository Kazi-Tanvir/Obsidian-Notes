# AI Daily Log: May 17, 2026

## Key Focus Areas
- **Hardware Performance**: Diagnosed lag and battery drain on the primary laptop (HP 14s-cf2).
- **Network Security**: Configured AdGuard DNS profiles on Windows.
- **Computer Science Fundamentals**: Practiced explaining low-level binary logic.

## Logged Activities & Context
### Laptop Lag & Throttling
- **Context**: Laptop lag spikes occurring only when plugged into AC power.
- **Actions Taken**: Audited CPU speed metrics inside Task Manager and checked power configurations.
- **Key Takeaways**: Throttling was caused by thermal spikes when Windows unthrottled CPU states on AC power, triggering panic speed drops to 0.8 GHz. Recommended propping up laptop vents or cleaning fans.

### Battery Lifespan Audit
- **Context**: Battery backup dropping below 2-3 hours during normal use.
- **Actions Taken**: Generated a Windows battery report (`powercfg /batteryreport`) and checked GPU preferences.
- **Key Takeaways**: The battery physical health was intact. Drains were caused by background developer servers and the dedicated AMD GPU running the web browser. Forcing Brave to use the integrated Intel GPU extends runtime.

### AdGuard DNS Integration
- **Context**: Blocking network ads without local browser extension bloat.
- **Actions Taken**: Configured IPv4 network DNS parameters.
- **Key Takeaways**: Implementing DNS filtering at the OS level intercepts ad domains before they resolve.
