# AI Daily Log: April 09, 2026

## Key Focus Areas
- **Front-End Development**: Analyzed rendering methods (SSR, SSG, ISR) and configured Next.js App Router hooks.
- **Git Administration**: Handled Git push timeouts on heavy binaries and wrote `.gitignore` rules.
- **Database Management**: Resolved safe updates locks inside MySQL Workbench.

## Logged Activities & Context
### SSR vs. SSG vs. ISR
- **Context**: Understanding Next.js caching models.
- **Actions Taken**: Documented page delivery concepts: SSG pre-packages pages, SSR builds pages dynamically on request, and ISR updates static pages incrementally.
- **Key Takeaways**: SSG is optimal for static content, SSR for user dashboards, and ISR for scaling e-commerce catalogues.

### Next.js App Router Routing
- **Context**: Debugging routing errors (`NextRouter was not mounted`).
- **Actions Taken**: Replaced old `next/router` imports with `next/navigation` hooks (useRouter and useParams).
- **Key Takeaways**: Next.js App Router requires navigation hooks to be imported from next/navigation.

### Git Push Binary timeouts
- **Context**: Fixing failed push timeouts (2.06 GiB initial commit upload failure).
- **Actions Taken**: Reset the commit staging area, wrote `.gitignore` rules to exclude heavy program directories, and re-pushed the repository.
- **Key Takeaways**: Git is optimized for tracking text files, not heavy installers. Restricting binaries keeps upload times minimal.

### MySQL Safe Updates Mode
- **Context**: Resolving deletion blocks (Error 1175).
- **Actions Taken**: Toggled off "Safe Updates" in Workbench preferences.
- **Key Takeaways**: Safe updates prevent deletes/updates without a Primary Key in the WHERE clause, protecting table integrity.
