### Handshaking Lemma Application
- **Context**: Solving degree worksheets.
- **Actions Taken**: Solved equations to find vertex counts of specific degree distributions.
- **Key Takeaways**: By the Handshaking Lemma, the sum of degrees of all vertices equals twice the number of edges ($\sum \deg(v) = 2e$). For a graph with 11 vertices and 19 edges, the number of vertices with degree 3 is 6, and the number of vertices with degree 4 is 5.

### Keyboard Layout Overrides
- **Context**: Disabling malfunctioning arrow keys on an Acer laptop.
- **Actions Taken**: Wrote an AutoHotkey (`.ahk`) script to block arrow key signals and mapped them to run at Windows startup.
- **Key Takeaways**: Script-based keyboard blocking resolves hardware loops from sticky or physically damaged keys without opening the device chassis.
