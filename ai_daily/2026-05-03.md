## Logged Activities & Context
### C Change Calculator Optimization
- **Context**: Debugging a change calculator utilizing coins of 25, 10, 5, 2, and 1.
- **Actions Taken**: Fixed a logic bug where inputs smaller than 25 bypassed the division steps, resulting in calculation drops. Refactored the code using arrays and a clean 5-step loop.
- **Key Takeaways**: Storing denominations in arrays ensures that smaller inputs are checked against all lower values, guaranteeing mathematical precision.

### Integer Reversal in C
- **Context**: Swapping digit layouts.
- **Actions Taken**: Coded two reversing methods: a modulo 10 math loop, and a character array swap loop using symmetric pointer offsets (`length - 1 - i`).
- **Key Takeaways**: Reversing via string buffers bypasses integer overflow risks associated with massive numbers.

### Exact Age Calculator

- **Actions Taken**: Created a C application utilizing the `<time.h>` library to fetch current system dates automatically, rather than requiring manual calendar inputs from users.
- **Key Takeaways**: Computing year/month/day differences requires adjusting for negative day balances based on varying monthly limits.

### Monty Hall Problem Analysis
- **Context**: Analyzing mathematical logic patterns.
- **Actions Taken**: Calculated probability differences when switching doors vs. staying.
- **Key Takeaways**: Switching doors increases the probability of winning from 1/3 (33.3%) to 2/3 (66.7%) because the host's action filters out an incorrect choice.
