## Logged Activities & Context
### 64-Bit C++ Standard Input
- **Context**: Compiling mathematical code requiring large number parsing (up to $10^{12}$).
- **Actions Taken**: Converted C standard functions into C++ `std::cin` streams.
- **Key Takeaways**: C++ standard streams natively format 64-bit integers (`long long`) without requiring platform-dependent specifiers like `%lld` or `%I64d`.

### C Compiler Terminal Lockouts
- **Context**: Resolving compile failures where Windows refused to overwrite execution binaries.
- **Actions Taken**: Audited active process logs in PowerShell and identified background loop hangs.
- **Key Takeaways**: Windows file locks prevent rebuilding active binaries. Terminating hanging processes via `taskkill /f /im main.exe` immediately releases folder hooks.

### Ternary Operator Precedence
- **Context**: Fixing syntax errors in compressed C loops.
- **Actions Taken**: Evaluated why the statement `n[0] > 0?n[0]--:r -= p[0]` crashed compilation.
- **Key Takeaways**: The assignment operator (`-=`) has lower precedence than the conditional ternary (`? :`). Adding grouping parentheses around the assignment statement (`(r -= p[0])`) resolves the compile error.
