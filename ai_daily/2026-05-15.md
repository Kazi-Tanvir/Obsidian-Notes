## Key Focus Areas

## Logged Activities & Context
### C Accumulator Loop Debugging
- **Context**: Fixing calculation logs that return garbage values (e.g. total 4,199,604) in room square footage programs.
- **Actions Taken**: Identified missing variable initializations (`total = 0`) and fixed print indentations.
- **Key Takeaways**: Uninitialized numbers fetch random storage values. Spacing after newlines (`\n `) inside loop prints shifts subsequent logs.

### C String Comparisons
- **Context**: Debugging password checkers using standard libraries.
- **Actions Taken**: Audited compilation errors when comparing character arrays via the equality operator (`if (pass == confirm)`).
- **Key Takeaways**: In C, array variables represent storage locations rather than content values. Content comparisons require character loops or standard strcmp libraries.

### Advanced Search Algorithms
- **Context**: Evaluating logic paths that outperform binary search.
- **Actions Taken**: Audited log limits for Interpolation Search.
- **Key Takeaways**: Standard binary search runs in $O(\log n)$ time. For uniformly distributed data, Interpolation Search scales in $O(\log \log n)$ by guessing placement locations using proportional scaling.
