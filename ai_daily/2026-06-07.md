# AI Daily Log: June 07, 2026

## Key Focus Areas
- **Project Dev (VoxAgent)**: Completed MVP! Evaluated production roadmap, database hosting options, and localized latency optimization.
- **Web Security**: Investigated WebRTC and microphone permissions in browser testing environments.
- **Database Architecture**: Implemented doctors' database schema in MySQL.
- **Healthcare Simulation**: Rehearsed patient scheduling flows via voice integration.

## Logged Activities & Context
### VoxAgent Production Estimation
- **Context**: Transitioning from prototype to enterprise-ready healthcare SaaS.
- **Actions Taken**: Conducted feasibility review of multi-tenancy requirements, data privacy compliance, and hospital EHR integrations.
- **Key Takeaways**: A production release requires 3-4 months. Latency checks must remain below 1.5 seconds to keep conversations natural.

### Vercel vs. Netlify (Next.js hosting)
- **Context**: Sourcing production cloud servers for Next.js and Prisma.
- **Actions Taken**: Compared speed optimization parameters of Vercel and Netlify.
- **Key Takeaways**: Vercel is selected. It features native, zero-config integration for Server Actions and matches Vapi's US server regions (AWS us-east-1), resolving BDT latency loops.

### MySQL Schema Deployment
- **Context**: Creating doctors' schedule tables.
- **Actions Taken**: Generated and executed a MySQL script to build a `doctors` table and populated it with 6 specialists (Vance, Thorne, Zhang, Patel, Lindqvist, Lin).
- **Key Takeaways**: Table schema verified on localhost. Linked active states via `is_active` boolean markers.

### Browser WebRTC Policies
- **Context**: Accessing mic prompts during mobile testing.
- **Actions Taken**: Diagnosed why phone calls failed on local IP addresses (`http://192.168.0.191:3000`).
- **Key Takeaways**: WebRTC media capture APIs require secure origins (`https` or `localhost`). Standardized mobile testing calls through secure ngrok tunnels.
