# AI Daily Log: March 31, 2026

## Key Focus Areas
- **Database Management**: Studied Mongoose database collection naming mappings.
- **Front-End Development**: Coded dummy data generators and analyzed Tailwind CSS modularity benefits.
- **System Administration**: Audited packages dependencies setups.

## Logged Activities & Context
### Mongoose Collection Naming Mapped
- **Context**: Interacting with MongoDB databases using Mongoose.
- **Actions Taken**: Clarified Mongoose naming structures.
- **Key Takeaways**: Defining a model in Mongoose automatically maps it to a pluralized, lowercase collection name (e.g. `Employee` models compile to query `employees` collections).

### Tailwind CSS Class Bloat vs. React Components
- **Context**: Managing Tailwind CSS readability.
- **Actions Taken**: Audited Tailwind's inline class usage compared to separate CSS files.
- **Key Takeaways**: Tailwind classes look verbose in raw HTML but become clean and maintainable when packaged inside React components.

### Express/Node.js Data Generator
- **Context**: Generating dummy collections for database seeds.
- **Actions Taken**: Structured a modular data generator (creating a helper generator script inside `utils/dataGenerator.js` and database operations using `insertMany` in `main.js`).
- **Key Takeaways**: Using `insertMany` groups operations into a single query, which runs faster than executing separate insert calls in a loop.

### dependencies vs. devDependencies
- **Context**: Learning package configuration parameters.
- **Actions Taken**: Compared structural dependencies types. Resolved Tailwind v4 configuration mismatch errors by downgrading package versions to Tailwind v3 (`npm install -D tailwindcss@3`).
- **Key Takeaways**: Dependencies are needed for runtime environments, while devDependencies serve compilation purposes.
