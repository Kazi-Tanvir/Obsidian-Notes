# AI Daily Log: June 08, 2026

## Key Focus Areas
- **Project Dev (VoxAgent)**: Established startup goals and rated feasibility guidelines for the AI medical receptionist.
- **Real-Time Architectures**: Researched WebSockets and Redis caching operations.
- **Local Telephony Research**: Sourced Bangla speech transcribers.
- **Environment Management**: Configured VS Code to run C programs on Windows.

## Logged Activities & Context
### VoxAgent Project Kickoff
- **Context**: Tech lead planning to build a multi-tenant healthcare customer service voice agent with two co-founders.
- **Actions Taken**: Wrote a background document and rated feasibility metrics in `overallProjects.md`.
- **Key Takeaways**: Standard STT models fail on regional dialects (Noakhailla, Chatgaiya). Recommended narrowing scope to a highly constrained "Appointment Confirmation and Cancellation Bot" using standard Bangla first.

### WebSocket & Redis Foundations
- **Context**: Managing concurrent telephone lines.
- **Actions Taken**: Explored why persistent WebSocket connections and Redis pub/sub are required to handle streaming audio buffers without blocking backend execution loops.
- **Key Takeaways**: WebSockets maintain the audio pipeline, and Redis serves as a high-speed database queue to hold call states.

### C Language VS Code Setup
- **Context**: Setting up a C programming workspace from scratch on Windows.
- **Actions Taken**: Configured MSVC / w64devkit compilers and adjusted VS Code settings to run code runner inside the integrated terminal.
- **Key Takeaways**: Enabling "Run In Terminal" allows using interactive functions like `scanf` without read-only blocks.

## Insights & Discoveries
- **Backend Language Trade-Offs**: Evaluated Node.js (unified JS ecosystem) vs. Python/FastAPI. Selected Python for its native AI/ML libraries and Whisper model self-hosting integrations.
