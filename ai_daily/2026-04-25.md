## Logged Activities & Context
### C Integer Division Gotcha
- **Context**: Fixing math calculations returning 0.000000 outputs.
- **Actions Taken**: Identified how standard division between integers returns truncated fractions, and fixed it by casting variables as floats before division.
- **Key Takeaways**: In C, dividing two integers forces integer outputs. Safe calculations require explicit float conversions (`(float)numerator / denominator`).

### Local CS50 Library Imports
- **Context**: Importing Harvard's custom C library (`cs50.h`) on Windows.
- **Actions Taken**: Outlined installation steps: downloading header files, placing them in compiler directories, and telling GCC where to locate files during compile calls.
- **Key Takeaways**: Standard tools compile local files without library paths; custom headers require link instructions.

### Enum Runtime Limitations
- **Context**: Assigning Scrabble-style scores to alphabets A-Z.
- **Actions Taken**: Audited why `enum` constructs failed during user input scans.
- **Key Takeaways**: Enums resolve during compile time. Runtime string evaluations cannot dynamically map to enum variable labels. Scrabble score evaluations require array mappings.

### Windows 11 Bootable USB Drive
- **Context**: Setting up OS setup disks.
- **Actions Taken**: Audited Rufus vs. standard Media Creation tool options.
- **Key Takeaways**: Direct USB flash drive installation is standard. Sourcing Windows 11 installation files via ISO formats enables custom boot adjustments in Rufus.
