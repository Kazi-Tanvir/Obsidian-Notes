# AI Daily Log: April 04, 2026

## Key Focus Areas

## Logged Activities & Context
### React Hook Foundations
- **Context**: Mastering React state structures.
- **Actions Taken**: Reviewed hooks covered in tutorial logs: components, props, useState, useEffect, and useContext. Compared useMemo (caching complex mathematical computations) with useRef (persisting data quietly between renders without forcing state updates).
- **Key Takeaways**: useMemo prevents redundant heavy calculations, whereas useRef updates variables without triggering component re-renders.

### React Router Link Context Error
- **Context**: Resolving navigation failures when using `<Link>` tags.
- **Actions Taken**: Addressed console errors resulting from placing Router links outside the Router context.
- **Key Takeaways**: Standard navigation tags must be nested inside `<BrowserRouter>` wrappers to access layout contexts.

### VS Code SQLTools Setup
- **Context**: Querying MySQL directly from VS Code.
- **Actions Taken**: Installed the SQLTools extension, configured database connections targeting `startersql`, and ran basic creation queries.
- **Key Takeaways**: Utilizing database extensions within IDEs centralizes operations, replacing manual switches to MySQL Workbench.
